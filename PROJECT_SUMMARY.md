## 🏗️ Архитектура решения

### Android (MVVM + Repository pattern)
```
┌─────────────────────────────────────────┐
│         UI Layer (Activities)           │
│  LoginActivity → ContactsActivity       │
│                  → ChatActivity          │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│     Repository Layer                    │
│  MessageRepository (sendText, observe)  │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│         Data Layer                      │
│  Room DB (Messages, Users) + Network    │
│  SocketManager (SSL/TLS)                │
└─────────────────────────────────────────┘
```

### Server (Threaded Socket Server)
```
┌─────────────────────────────────────────┐
│      SSL/TLS Socket Layer               │
│  Принимает соединения на порту 12345    │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│     Command Handler                     │
│  AUTH, LIST_USERS, SEND_MSG, UPLOAD     │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│     Business Logic                      │
│  Аутентификация, отправка сообщений     │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│      SQLite Database                    │
│  users, messages, groups, members       │
└─────────────────────────────────────────┘
```

## 🔐 Безопасность

### Реализованные меры
1. **SSL/TLS шифрование** всех соединений
2. **Хеширование паролей** с уникальной солью (SHA-256)
3. **Изоляция данных** пользователей
4. **Защита от SQL injection** (parametrized queries)

### Рекомендации для продакшена
1. Использовать сертификаты от Let's Encrypt
2. Настроить файрвол
3. Регулярное обновление системы
4. Мониторинг логов безопасности

## 🚀 Как начать использовать

### За 5 минут:

**Сервер:**
```bash
cd server
./generate_certs.sh
python3 main.py
```

**Android:**
1. Открыть в Android Studio
2. Изменить IP в LoginActivity.kt
3. Run → Run 'app'

**Вход:**
- Логин: user1
- Пароль: password1

См. [QUICKSTART.md](QUICKSTART.md) для подробностей.

## 🎓 Примеры использования

### Пример 1: Отправка сообщения
```kotlin
// В ChatActivity
btnSend.setOnClickListener {
    val text = etMessage.text.toString()
    if (text.isNotEmpty()) {
        repo.sendText(recipientId, text)
        etMessage.text.clear()
    }
}
```

### Пример 2: Серверный протокол
```python
# Авторизация
"AUTH:username:password"
# Ответ: "ACK" или "FAIL"

# Отправка сообщения
'SEND_MSG:{"recipient_id":2,"text":"Hello"}'
# Ответ: "MSG_SENT:123"
```

### Пример 3: Запрос пользователей
```python
# Запрос
"LIST_USERS"
# Ответ
'USERS:[{"id":1,"username":"user1"},{"id":2,"username":"user2"}]'
```
