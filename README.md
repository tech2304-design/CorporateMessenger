# Корпоративный Мессенджер

Мессенджер для организаций до 250 человек с Android-клиентом и простым сервером.

## Возможности

- ✅ Отправка текстовых сообщений
- ✅ Отправка файлов и фотографий  
- ✅ Список контактов для выбора получателя
- ✅ Отображение статуса пользователей (в сети/не в сети)
- ✅ Уведомления с звуком при получении сообщений (только когда приложение свернуто)
- ✅ Простой в установке сервер на Python
- ✅ Безопасное соединение через SSL/TLS
- ✅ База данных SQLite для хранения сообщений
- ✅ Логирование работы сервера с режимом отладки

## Установка и запуск сервера

### Требования
- Python 3.8 или выше
- OpenSSL (для генерации сертификатов)

### Шаги

1. **Генерация SSL сертификатов**:
   ```bash
   cd server
   chmod +x generate_certs.sh
   ./generate_certs.sh
   ```

2. **Запуск сервера**:
   ```bash
   # Обычный режим (логи в файл)
   python3 main.py
   
   # Режим отладки (логи на экран и в файл)
   python3 main.py -d
   # или
   python3 main.py --debug
   ```

Сервер запустится на порту 12345 и создаст:
- `data/messenger.db` - база данных SQLite
- `data/uploads/` - директория для загруженных файлов
- `logs/` - директория для логов (создается автоматически)
- Тестовые пользователи: user1/password1, user2/password2, user3/password3, admin/admin

**Параметры запуска:**
- `-d` или `--debug` - режим отладки, выводит детальные логи на экран
- По умолчанию сервер выводит только стартовые сообщения, все остальное пишется в файлы логов

### Перенос на другой сервер

Просто скопируйте директорию `server/` на новый сервер и запустите `python3 main.py`.
Все данные хранятся в `data/messenger.db`.

## Настройка Android приложения

### Требования
- Android Studio Arctic Fox или новее
- Android SDK 24+ (Android 7.0+)

### Шаги

1. **Открыть проект в Android Studio**:
   - Открыть папку проекта в Android Studio
   - Дождаться синхронизации Gradle

2. **Настроить IP адрес сервера**:
   В файле `app/src/main/java/com/example/messenger/ui/LoginActivity.kt`:
   ```kotlin
   SocketManager.connect("YOUR_SERVER_IP", 12345)
   ```
   Замените `YOUR_SERVER_IP` на IP адрес вашего сервера.
   Для эмулятора используйте `10.0.2.2` (localhost хоста).

3. **Собрать и установить приложение**:
   - Подключить Android устройство или запустить эмулятор
   - Нажать "Run" в Android Studio

## Использование

### Вход в систему
1. Запустите приложение
2. Введите логин и пароль (например: user1 / password1)
3. Нажмите "Login"

### Отправка сообщений
1. После входа откроется экран "Контакты"
2. Выберите пользователя из списка
3. Введите сообщение и нажмите "Send"

### Отправка файлов
1. В чате нажмите кнопку "Attach"
2. Выберите файл или фото
3. Файл будет прикреплен к сообщению

### Уведомления
- Приложение показывает уведомления с звуком при получении новых сообщений
- Уведомления отображаются **только когда приложение свернуто**
- Если приложение открыто, сообщения отображаются без уведомлений
- При первом запуске на Android 13+ потребуется разрешить уведомления

### Статус пользователей
- В списке контактов отображается статус каждого пользователя
- 🟢 Зеленый индикатор - пользователь в сети
- ⚫ Серый индикатор - пользователь не в сети
- Статус обновляется при обновлении списка контактов

## Функции сервера

### Команды протокола
- `AUTH:username:password` - Авторизация
- `LIST_USERS` - Получить список пользователей (с информацией о статусе онлайн)
- `SEND_MSG:{"recipient_id":N,"text":"..."}` - Отправить сообщение
- `GET_MESSAGES:other_user_id` - Получить историю сообщений с пользователем
- `UPLOAD_FILE:{"recipient_id":N,"filename":"..."}` - Загрузить файл

### Логирование
- Сервер записывает все события в файлы логов в директории `logs/`
- Файлы логов создаются ежедневно: `messenger_YYYYMMDD.log`
- В обычном режиме логи пишутся только в файл
- В режиме отладки (`-d`) логи дублируются на экран
- Логируются: подключения, авторизации, сообщения, ошибки

### Резервное копирование
```bash
cd server
python3 backup_db.py
```

## Архитектура

### Android
- **Язык**: Kotlin
- **БД**: Room (SQLite)
- **UI**: Activities, RecyclerView
- **Сеть**: SSL Sockets
- **Асинхронность**: Kotlin Coroutines

### Сервер  
- **Язык**: Python 3
- **БД**: SQLite3
- **Сеть**: SSL/TLS сокеты
- **Многопоточность**: Threading

## Безопасность

- Все соединения защищены SSL/TLS
- Пароли хешируются с солью (SHA-256)
- База данных локальная, без внешних зависимостей

## Масштабирование

Текущая реализация рассчитана на ~250 пользователей. Для больших организаций рекомендуется:
- Использовать PostgreSQL вместо SQLite
- Добавить Redis для кеширования
- Реализовать WebSocket для real-time обновлений
- Добавить балансировку нагрузки
