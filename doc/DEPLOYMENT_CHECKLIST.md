# Чеклист развёртывания

## Подготовка сервера

### 1. Системные требования
- [ ] Python 3.8+ установлен
- [ ] OpenSSL установлен
- [ ] Порт 12345 доступен
- [ ] Минимум 1GB RAM
- [ ] Минимум 10GB свободного места на диске

### 2. Установка сервера
- [ ] Репозиторий склонирован
- [ ] Перешли в директорию `server/`
- [ ] Сгенерированы SSL сертификаты (`./generate_certs.sh`)
- [ ] Сертификаты присутствуют в `certs/cert.pem` и `certs/key.pem`

### 3. Первый запуск
- [ ] Запущен сервер (`python3 main.py`)
- [ ] Сервер слушает на порту 12345
- [ ] База данных создана в `data/messenger.db`
- [ ] Тестовые пользователи созданы
- [ ] Нет ошибок в консоли

### 4. Сетевая настройка
- [ ] Файрвол настроен (порт 12345 открыт)
- [ ] Определён внешний IP адрес сервера
- [ ] Сервер доступен из локальной сети

### 5. Безопасность
- [ ] Изменены пароли тестовых пользователей
- [ ] Настроен SSH доступ только по ключу (для удалённого сервера)
- [ ] Настроено резервное копирование базы данных
- [ ] Логи настроены и проверяются
