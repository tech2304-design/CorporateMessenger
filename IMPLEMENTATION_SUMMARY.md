# Реализованные возможности

## Краткое описание

Проект был подготовлен к запуску с добавлением всех запрошенных функций:

### 1. ✅ Звук уведомлений (notification_sound.wav)
- Создан файл со звуком уведомления в `app/src/main/res/raw/notification_sound.wav`
- Длительность: 500 мс, формат: WAV, частота: 800 Hz с затуханием
- Звук воспроизводится при получении новых сообщений

### 2. ✅ Уведомления с условием минимизации
- Реализован класс `NotificationHelper` для управления уведомлениями
- Уведомления показываются **только когда приложение свернуто**
- Если приложение открыто, сообщения отображаются без уведомлений
- Добавлена проверка статуса приложения через `isAppInForeground()`
- Добавлены разрешения `POST_NOTIFICATIONS` и `VIBRATE` в манифест

### 3. ✅ Отображение статуса пользователей в списке контактов
- Добавлено поле `isOnline` в `UserEntity`
- Сервер отслеживает онлайн-статус пользователей в глобальном множестве `online_users`
- При подключении пользователь добавляется в список онлайн
- При отключении удаляется из списка
- Команда `LIST_USERS` теперь возвращает поле `isOnline` для каждого пользователя
- Создан пользовательский layout `item_contact.xml` с индикатором статуса
- Создан drawable `status_indicator.xml` с зеленым и серым кругом
- Обновлен `ContactsAdapter` для отображения:
  - Имя пользователя
  - Статус "В сети" / "Не в сети"
  - Цветной индикатор (🟢 зеленый для онлайн, ⚫ серый для офлайн)

### 4. ✅ Параметры запуска сервера
- Добавлен модуль `argparse` для обработки аргументов командной строки
- Реализован флаг `-d` / `--debug` для режима отладки
- В обычном режиме:
  - Показываются стартовые сообщения (запуск, инициализация БД)
  - Все дальнейшие логи пишутся в файлы в директории `logs/`
  - Пользователю показывается сообщение о записи логов в файл
- В режиме отладки (`-d`):
  - Логи дублируются на экран и в файл
  - Показываются все события: подключения, авторизации, сообщения, ошибки
- Система логирования:
  - Ежедневные файлы логов: `messenger_YYYYMMDD.log`
  - Формат: `YYYY-MM-DD HH:MM:SS - LEVEL - Message`
  - Уровни: DEBUG, INFO, WARNING, ERROR
  - Логируются: старт сервера, подключения, аутентификации, отправка сообщений, загрузка файлов, ошибки

### 5. ✅ Подготовка проекта к запуску
- Создан файл `QUICKSTART.md` с пошаговой инструкцией по запуску
- Обновлен `README.md` с документацией новых возможностей
- Добавлен Gradle wrapper для сборки Android приложения
- Проверена работа сервера в обоих режимах (обычный и debug)

- Обновлен `get_users_list()` - возвращает статус онлайн
- Обновлен `handle_client()` - добавляет/удаляет пользователей из online_users

**Изменения в протоколе:**

**Новые файлы:**
- `utils/NotificationHelper.kt` - управление уведомлениями
- `res/drawable/ic_notification.xml` - иконка для уведомлений

- `res/layout/item_contact.xml` - layout элемента списка контактов
- `res/raw/notification_sound.wav` - звук уведомления

**Обновленные файлы:**
- `AndroidManifest.xml` - добавлены разрешения для уведомлений
- `data/entities/UserEntity.kt` - добавлено поле isOnline
- `ui/ContactsActivity.kt` - парсинг isOnline из ответа сервера
- `ui/ContactsAdapter.kt` - отображение статуса в UI
- `ui/ChatActivity.kt` - показ уведомлений при получении сообщений в фоне

**Логика уведомлений:**
```kotlin

if (senderId == recipientId && !NotificationHelper.isAppInForeground(context)) {
    NotificationHelper.showMessageNotification(...)
}
```

## Использование

### Запуск сервера
```bash
# Обычный режим (логи в файл)
cd server
python3 main.py

# Режим отладки (логи на экран и в файл)
python3 main.py -d
```

### Просмотр логов
```bash
# В реальном времени
tail -f server/logs/messenger_$(date +%Y%m%d).log

# Последние 50 строк
tail -50 server/logs/messenger_$(date +%Y%m%d).log
```

### Тестирование уведомлений
1. Запустите приложение на двух устройствах
2. Войдите как разные пользователи (user1 и user2)
3. На первом устройстве сверните приложение (нажмите Home)
4. На втором устройстве отправьте сообщение
5. На первом устройстве должно появиться уведомление со звуком

### Проверка статусов
1. Войдите на двух устройствах как разные пользователи
2. В списке контактов должен быть виден зеленый индикатор 🟢 рядом с именем другого пользователя
3. Если пользователь выйдет, индикатор станет серым ⚫
