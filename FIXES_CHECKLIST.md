## 🔴 КРИТИЧЕСКИЙ ПРИОРИТЕТ (Must-Have)

### Серверная часть
- [ ] **Реализовать парсинг команд протокола**
  - [ ] AUTH:username:password
  - [ ] LIST_USERS
  - [ ] SEND_MSG:json
  - [ ] UPLOAD_FILE:json
  
- [ ] **Подключить сервер к базе данных SQLite**
  - [ ] Инициализация БД при запуске
  - [ ] Параметризованные запросы (защита от SQL Injection)
  
- [ ] **Реализовать аутентификацию пользователей**
  - [ ] Проверка username/password с хешами из БД
  - [ ] Ответ ACK:user_id при успехе
  - [ ] Ответ FAIL:message при ошибке
  
- [ ] **Инициализация тестовых пользователей**
  - [ ] user1/password1
  - [ ] user2/password2
  - [ ] user3/password3
  - [ ] admin/admin
  
- [ ] **Сохранять сообщения в БД**
  - [ ] INSERT в таблицу messages
  - [ ] Вернуть MSG_SENT:message_id
  
- [ ] **Маршрутизация сообщений получателям**
  - [ ] Хранить активные соединения (username -> conn)
  - [ ] Отправлять уведомления онлайн-получателям

### Клиентская часть (Android)

- [ ] **Держать соединение открытым**
  - [ ] Не вызывать disconnect() после авторизации
  - [ ] Создать singleton для управления соединением
  
- [ ] **Реализовать фоновый слушатель входящих сообщений**
  - [ ] Service или WorkManager
  - [ ] Обработка команды NEW_MSG:json от сервера
  - [ ] Сохранение в локальную БД
  - [ ] Уведомление UI (LiveData/Flow)
  
- [ ] **Сохранять ID текущего пользователя**
  - [ ] В SharedPreferences после успешной авторизации
  - [ ] Использовать вместо senderId = 0
  
- [ ] **Реализовать загрузку файлов**
  - [ ] Заполнить FileUploader.upload()
  - [ ] Отправка байтов на сервер
  - [ ] Прогресс-бар загрузки
  
- [ ] **Серверная обработка файлов**
  - [ ] Получение файла по сети
