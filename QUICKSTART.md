# Быстрый старт для запуска проекта

## Серверная часть

### 1. Проверка зависимостей
Убедитесь, что у вас установлен Python 3.8+:
```bash
python3 --version
```

### 2. Запуск сервера

Перейдите в директорию сервера:
```bash
cd server
```

Запустите сервер в обычном режиме (логи в файл):
```bash
python3 main.py
```

Или в режиме отладки (логи на экран):
```bash
python3 main.py -d
```

### Что произойдет при первом запуске:
1. Создастся директория `data/` с базой данных `messenger.db`
2. Создастся директория `data/uploads/` для загружаемых файлов
3. Создастся директория `logs/` для файлов логов
4. Будут созданы тестовые пользователи:
   - user1 / password1
   - user2 / password2
   - user3 / password3
   - admin / admin

### Проверка работы сервера:
```bash
# Сервер должен вывести:
[+] Starting Corporate Messenger Server...
[+] Debug mode: OFF
[+] Logs will be written to logs/
[+] Database initialized
[+] Database initialization complete
[+] Server is now running. All further logs will be written to file.
[+] Use -d flag to see debug output on console.
[+] Server listening on 0.0.0.0:12345
```

### Просмотр логов:
```bash
# Текущие логи
tail -f logs/messenger_$(date +%Y%m%d).log

# Последние 50 строк
tail -50 logs/messenger_$(date +%Y%m%d).log
```

## Android клиент

### 1. Требования
- Android Studio Arctic Fox или новее
- Android SDK 24+ (Android 7.0+)
- Gradle будет установлен автоматически при первой сборке

### 2. Открытие проекта
1. Откройте Android Studio
2. File → Open → выберите корневую директорию проекта
3. Дождитесь синхронизации Gradle (может занять несколько минут при первом запуске)

### 3. Настройка IP адреса сервера

Если сервер запущен НЕ на том же компьютере, измените IP в следующих файлах:

**LoginActivity.kt** (строка 38):
```kotlin
SocketManager.connect("YOUR_SERVER_IP", 12345)
```

**ContactsActivity.kt** (строка 60):
```kotlin
SocketManager.connect("YOUR_SERVER_IP", 12345)
```

**ChatActivity.kt** (строки 89, 132, 194):
```kotlin
SocketManager.connect("YOUR_SERVER_IP", 12345)
```

**Для тестирования:**
- **На эмуляторе**: используйте `10.0.2.2` (это localhost хост-машины)
- **На реальном устройстве**: используйте локальный IP сервера (например, `192.168.1.100`)

### 4. Сборка и запуск

**Через Android Studio:**
1. Подключите Android устройство или запустите эмулятор
2. Нажмите зеленую кнопку Run (▶️) или Shift+F10
3. Приложение будет собрано и установлено

**Через командную строку:**
```bash
# Сборка debug версии
./gradlew assembleDebug

# APK будет создан в:
# app/build/outputs/apk/debug/app-debug.apk

# Установка на подключенное устройство
./gradlew installDebug
```

## Тестирование

### Базовый тест (2 пользователя):

1. **На первом устройстве/эмуляторе:**
   - Запустите приложение
   - Войдите как `user1` / `password1`
   - Откроется список контактов

2. **На втором устройстве/эмуляторе:**
   - Запустите приложение
   - Войдите как `user2` / `password2`
   - Откроется список контактов

3. **Проверка статусов:**
   - В списке контактов должен быть виден другой пользователь
   - Рядом с именем должен быть зеленый индикатор (🟢) - пользователь в сети

4. **Отправка сообщений:**
   - На первом устройстве выберите user2
   - Отправьте сообщение "Hello!"
   - На втором устройстве выберите user1
   - Вы должны увидеть полученное сообщение

5. **Тест уведомлений:**
   - Сверните приложение на первом устройстве (нажмите Home)
   - На втором устройстве отправьте сообщение user1
   - На первом устройстве должно появиться уведомление со звуком

### Проверка логов сервера:
```bash
# Смотрите в режиме реального времени
cd server
python3 main.py -d
# Теперь все действия будут видны на экране
```

## Возможные проблемы

### Сервер не запускается
```
Error: [SSL] PEM lib
```
**Решение:** Сертификаты не найдены. Создайте их:
```bash
cd server
chmod +x generate_certs.sh
./generate_certs.sh
```

### Приложение не может подключиться
```
Ошибка подключения: Connection refused
```
**Решения:**
1. Проверьте, что сервер запущен
2. Проверьте IP адрес в коде приложения
3. Проверьте, что порт 12345 не заблокирован файрволом
4. На Linux: `sudo ufw allow 12345`

### Нет уведомлений на Android 13+
**Решение:** Приложение запросит разрешение при первом запуске чата. Если не появилось:
1. Настройки → Приложения → Messenger → Уведомления
2. Включите уведомления

### Gradle sync failed
```
Could not resolve dependencies
```
**Решение:** Проверьте интернет-соединение и повторите синхронизацию
